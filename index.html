      More options

      The installer writes the Sipeed debugger file at flash address 0x0 and the Tango firmware at 0x40000 of the BL616 flash, as one image with empty space (0xFF) between them.

      Leave these off unless you know you need them.

      2. Connect the board in update mode

      1. Unplug every cable that powers the board, including the FPGA USB-C port and any power supply.
      2. Hold the BOOT button. It is on the underside of the board, next to the MCU USB-C port. (See image here for the BOOT button)
      3. Plug a USB cable from this computer into the MCU USB-C port, then let go of BOOT.
      4. Click Connect and pick Bouffalo CDC DEMO from the list.

      3. Install
